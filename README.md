# Peripera 웹 디자인 포트폴리오

HTML, CSS, JavaScript로 제작한 정적 웹사이트입니다. React, npm 설치, 빌드 과정 없이 실행할 수 있습니다.

## 실행 및 수정

`index.html`을 브라우저에서 열거나 VS Code의 Live Server로 실행하세요.

- `index.html`: 페이지 구성과 텍스트
- `css/style.css`: 전체 디자인과 반응형 스타일
- `js/main.js`: 콜라주 클릭, 메뉴, 제품 목록 드래그, 카드 드래그, 타이핑, 스크롤 전환, 갤러리, TOP 버튼
- `images/`: 이미지
- `fonts/`: 폰트

이미지와 폰트 경로는 상대 경로이므로 폴더 전체를 함께 복사하면 됩니다.

## 배포

GitHub Pages에서는 저장소 루트의 정적 파일을 게시하면 됩니다. Vercel의 정적 사이트 설정은 `vercel.json`에 포함되어 있습니다. 기존 React 빌드 설정을 외부 배포 워크플로에서 지정한 경우 해당 설정도 정적 사이트에 맞게 변경하세요.

이 프로젝트는 개인 포트폴리오이며 실제 상품 구매 기능은 제공하지 않습니다.
